# Teste - Validação de Senha

Este projeto implementa uma função para validar senhas conforme regras especificadas no desafio.

## Regras de validação

Uma senha válida deve:

- Possuir 9 ou mais caracteres
- Conter ao menos 1 número
- Conter ao menos 1 letra minúscula
- Conter ao menos 1 letra maiúscula
- Conter ao menos 1 caractere especial

Caracteres especiais permitidos:

@ # $ % ^ & * ( ) - +

Além disso, a senha **não pode conter caracteres repetidos**.

## Arquivos

- `validarSenha.js` → implementação da validação
- `validarSenha.test.js` → testes de unidade
